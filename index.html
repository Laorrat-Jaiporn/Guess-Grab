    How to Play

    1. 1

      Read the Clue

      Read the description carefully to understand which object you need to find.

    2. 2

      Find the Object

      Look around you and show the correct real-world object to the camera.

    3. 3

      Earn Points

      Find the correct object as quickly as possible to earn more points. The answer will be revealed during the final 10 seconds.

      Skip or Give Up

      Skip an object if you cannot find it. You can also give up, but your remaining turns will count as zero points.
